Data Multiplexors

  • 多路复用器（MUX）根据选择信号从多个输入中选一路输出。单比特选择线（n=1）下，输出为 。在数据通路中广泛用于选择数据来源。

ALU

  • ALU 由输入多路复用器配合加法器和减法器构成。通过控制信号选择运算类型（加法或减法），复用同一套加法器硬件。减法通过将减数取反加一后送入加法器实现。

Adder

  • 多位加法器由级联多个 1 位全加器构成。1 位全加器输入 a、b 和进位 c_in，输出 sum 和 c_out。sum 由三个输入的异或实现，c_out 由多数函数（任意两个输入为 1 则进位）实现。
  • 补码溢出检测：最高位的进位 XOR 次高位的进位 。当两者不同时表示溢出。

Subtractor

  • a - b = a + (-b)，将 b 取反并加 1 后使用相同加法器。

Building processor

  • 处理器本质上是一个复杂的状态机，由数据通路和控制单元组成，在每个时钟周期中更新状态。
  • 指令执行分为多个阶段，每个阶段对应一个逻辑块：
    • 取指令（IF）
    • 解码（ID）
    • 执行（EX）
    • 访问内存（MEM）
    • 写回寄存器（WB）
    • 多个阶段在同一个时钟周期内发生
  • 每条指令在执行过程中都会读取和更新寄存器、内存、程序计数器的状态。

R-type add instruction

  • 执行过程：PC 提供指令地址 → 指令存储器取出指令 → 寄存器堆读出 rs1 和 rs2 → ALU 执行运算 → 结果写回 rd。数据通路包含 PC、指令存储器、寄存器堆、ALU、数据存储器，以及连接各部件的数据选择器。

R-type sub instruction

  • 与 add 指令复用同一数据通路，仅通过 funct7 的第 30 位区分是 add 还是 sub，控制 ALU 执行相应运算。其余 R 类指令均可复用此设计。

immediate

  • 在 R 类数据通路基础上增加一个输入多路复用器，决定 ALU 的第二个操作数是寄存器 rs2 还是立即数。立即数从指令的低 12 位提取后需按符号扩展到 32 位。

加入 lw

  • 不为 load 指令设计新通路，在现有数据通路末尾增加数据选择器，从 ALU 结果和内存读取结果中选择写回寄存器的值。

加入 sw

  • 在数据通路中增加存储数据路径，将 rs2 的值连接到数据存储器的写数据端口。同时，立即数生成器需支持不同指令格式（I 类和 S 类的立即数位段位置不同），通过数据选择器切换。

分支指令

  • 分支指令需要计算目标地址（PC + 偏移）并评估分支条件。条件计算器输出是否等于和是否小于，通过逻辑组合得到其他条件结果。分支结果决定 PC 的下一值是 PC+4 还是分支目标。

jalr

  • jalr 与 I 类指令共用相同的立即数格式，通过 ALU 计算 rs1 + imm 作为跳转目标地址。其数据通路中多路复用器选择立即数而非 rs2 送入 ALU。

CSR(控制和状态寄存器)

  • CSR 不属于基本 ISA 但一般都会实现。CSR 类指令用于读写控制和状态寄存器（如异常地址、中断使能位等），其数据通路从 CSR 寄存器堆读取值送入 ALU 或写回。
  • System 类指令主要向操作系统提供服务（如系统调用、中断返回等），通过 CSR 寄存器堆进行特权级别切换。

控制单元

  • 控制单元负责产生数据通路中所有多路复用器的选择信号、ALU 控制信号、寄存器写使能、内存读写使能等。可根据指令的 opcode 和 funct 字段生成对应的控制字。
  • 实现方式有两种：使用只读存储器（ROM）作为真值表（简单、易扩展，但有冗余）；或使用组合逻辑门实现（更紧凑、高效）。
